# Interface localization

DevShelf ships typed English and Vietnamese message catalogs in `src/lib/i18n/en.ts` and `vi.ts`. `en` is the source of truth for keys; `vi` is typed as `Record<MessageKey, string>`, and `scripts/lib/i18n.test.ts` verifies both sides have identical keys and no empty strings.

The active locale is stored in the existing Dexie `preferences` table (`locale: "en" | "vi"`). `PreferencesProvider` writes `document.documentElement.lang` whenever it changes, and `useI18n()` returns a typed `t(key)` helper. The `T` component lets server-rendered pages use the same catalogs without becoming client components.

Book titles, author names, descriptions, source text and all reader content are never translated. Covers and Open Library metadata stay as supplied by their sources. Only interface copy is localized.

To add a message: add it to `en.ts`, add the same key to `vi.ts`, then run `npm test`.
